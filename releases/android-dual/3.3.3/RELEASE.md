# LeafLink Android 3.3.3

Bereits gekoppelte Handys können die Gerätewebseite ohne erneute Codeeingabe öffnen: **Einstellungen → verbundene Geräte → WEB**.

Die App fordert eine kurzlebige, einmalige Browserfreigabe über die bestehende verschlüsselte Geräteverbindung an. Gerätecode und dauerhafter Kopplungsschlüssel werden nicht an den Browser weitergegeben. Die Übergabe wird nach Einlösen aus der Adresszeile entfernt. Ein widerrufener Handyzugang verliert auch seine zugehörigen Browserfreigaben.

Für die automatische Anmeldung ist Firmware **3.3.4 Beta** erforderlich. Bei älterer Firmware bleibt der normale Browseraufruf verfügbar. Direkt eingegebene Adressen können weiterhin die Anmeldung mit dem Gerätecode benötigen.

Vorhandene Kopplungen, Einstellungen und Hauspläne bleiben erhalten. Android-Paket und Release-Zertifikat bleiben unverändert. Android 6 / API 23 oder neuer; HAPLA-Unterstützung bleibt erhalten. Das App-Update aktualisiert keine Lüfterfirmware.
