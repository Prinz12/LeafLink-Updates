# LeafLink Android 3.3.37 – bestätigte Installationsrichtung bleibt sichtbar

Eine ausbleibende Statusantwort entfernt nicht mehr die Markierung von Auto,
IN, OUT oder Physisch. Die Geräteansicht behält die zuletzt bestätigte Auswahl
bei und kennzeichnet sie bei einer fehlenden Antwort als „Zuletzt bestätigt“.
Bis eine aktuelle Antwort vorliegt, bleiben Änderungen gesperrt. Eine neue
bestätigte Geräteeinstellung ersetzt die vorherige Auswahl; Geräte werden
getrennt behandelt. Die App schaltet dadurch keine Installationsrichtung um.

Als Update installieren; Kopplungen und Einstellungen bleiben erhalten.
Für diese Anzeigekorrektur ist kein Firmwareupdate erforderlich.
